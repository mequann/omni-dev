# omni-dev ⚡

> **Universal Polyglot Dev Orchestrator & Intelligent Observability Engine**  
> Run your entire microservice & frontend stack concurrently with zero configuration—and get instant, human-readable explanations whenever anything fails.

---

## 🚀 Quick Run (No Installation Required)

You can run Omni immediately in any multi-service project with `npx`:

```bash
npx omni-dev dev
```

Or run diagnostics on your workspace:
```bash
npx omni-dev doctor
```

---

## 📦 Global Installation

```bash
npm install -g omni-dev
```

Once installed globally, you can use the `omni` command directly:
```bash
omni dev
```
